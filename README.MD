# Typora GitHub 主题代码块暗黑覆盖样式

## 这是什么？

这是一个 Typora 的 `.user.css` 覆盖文件，专门用于在**保留官方 GitHub 浅色主题所有非代码样式**的前提下，将代码块（围栏代码块与行内代码）单独替换为 **One Dark Pro** 暗黑风格。

换句话说：你的正文、标题、列表、表格、引用、链接等所有内容保持 GitHub 官方浅色主题原样不变，只有代码区域会变成深色背景、彩色语法高亮的暗黑风格。

## 核心效果

- **正文区域**：完全保留 GitHub 官方浅色主题，白底黑字，阅读体验不变
- **围栏代码块**（```）：
  - 背景色：`#1a1d29`（One Dark Pro 深蓝黑）
  - 字体：Consolas（英文）+ 微软雅黑（中文回退）
  - 圆角边框、适当内边距与外边距
  - 完整的 One Dark Pro 语法高亮配色（关键字紫、字符串绿、注释灰、函数蓝等）
- **行内代码**（`code`）：深色圆角背景 + 黄色高亮文字
- **编辑器内体验**：光标、选中文本、行号颜色均适配暗黑主题

## 前置条件

1. **Typora 主题选择**：必须在 Typora 中选择 **GitHub** 官方主题
2. **开启代码块行号**：`文件 → 偏好设置 → Markdown → 代码块 → 勾选「显示行号」`
3. **字体支持**：系统需安装 Consolas（Windows 11 默认自带）和微软雅黑（Windows 默认自带）

## 安装方法

1. 打开 Typora，进入 `文件 → 偏好设置 → 外观 → 打开主题文件夹`
2. 将 `github.user.css` 放入该文件夹（与 `github.css` 同目录）
3. 重启 Typora
4. 确认当前主题为 **GitHub**，代码块即自动生效

> **技术说明**：`.user.css` 是 Typora 官方支持的覆盖机制，无需修改原主题文件，升级 Typora 也不会丢失自定义样式。

## 配色来源

- 代码块配色与背景提取自开源项目 [ahanniga/typora-one-dark-pro](https://github.com/ahanniga/typora-one-dark-pro)
- 主文本色经过调亮处理（`#d8dee9c7`），确保在深色背景上具有足够可读性

## 适用环境

- **操作系统**：Windows 11（其他平台字体栈可能需要微调）
- **Typora 版本**：支持 `.user.css` 覆盖机制的版本（1.0 及以上）

## 文件结构

```
github.user.css          <-- 本文件（覆盖层）
github.css               <-- Typora 官方原始主题（无需修改，自动继承）
```

---

**总结**：如果你喜欢在 GitHub 浅色主题下写作，但又希望代码块呈现类似 VS Code One Dark Pro 的专业暗黑高亮效果，这个文件就是为你准备的。
